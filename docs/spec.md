## 一、编辑器内建

这些功能不依赖 Go 工具链也能工作，或属于编辑器通用能力。

### 1. 文本编辑
- 文本输入、删除、复制(C-S c)、粘贴(C-S v)
- 撤销(C-a r)、重做(C-a y)
- 多光标、多选、列选择(多选：双击按C-d多选，列选择：S-M 上下左右键)
- 行号、当前行高亮
- 括号匹配、自动缩进
- Tab/空格设置
- 查找、替换、跳转到行
- 基础代码折叠

### 2. 文件与项目界面
- 打开文件(C-a f)输入路径，如果对应的是一个文件夹那么就把文件夹内的文件列出来，选中文件/文件夹 右箭头键打开/进入
- 文件树(C- <Spacse>)
- 多标签页(顶部像vscode一样列出，M-数字切换9跳到最后一个。文件类型图标用字体自带的图标)
- 全局搜索(C-a s)
- 分屏(C-a 0上下，C-a 1左右)
- 文件状态标记，如未保存、只读

### 3. 编辑器交互
- 命令面板
- 快捷键绑定
- 主题、字体、字号
- 配置持久化
- 任务运行器 UI
- 输出面板
- 问题/错误列表面板
- 内置终端(C-a t 底部出现一行可以输入的地方，可以输入终端指令如ls,go run。输出结果单独标签页展示)

### 4. Go 相关但内建的部分
- Go 语法高亮
- Go 代码片段，如 `func`、`if err != nil`、`for range`
- 基础缩进规则
- 基础括号匹配
- LSP 客户端
  - 启动/连接 `gopls`
  - 发送请求
  - 接收响应
  - 展示补全弹窗、悬停浮层、诊断波浪线
- 调试客户端 UI
  - 断点图标
  - 单步按钮
  - 变量面板
  - 调用栈面板
- 错误输出解析与点击跳转
- 运行/测试按钮和快捷键

## 二、Go 工具链集成

这些功能依赖外部 Go 工具或服务，编辑器只是调用和展示。

### 1. 语言智能：`gopls`
- 自动补全
- 函数签名提示
- 悬停文档
- 跳转定义
- 跳转声明
- 查找引用
- 重命名符号
- 实时诊断
- 快速修复
- 包级/文件级符号跳转
- 语义高亮，可选
- 语义折叠，可选

### 2. 格式化与导入：`gofmt` / `goimports`
- 保存时格式化
- 自动整理 import
- 删除未使用 import
- 添加缺失 import

### 3. 构建、运行、测试：`go` 命令
- `go run`  C-g r
- `go build`  C-g b
- `go test`  C-g t
- `go vet`  C-g v
- `go mod tidy` C-g-m t
- `go mod download` C-g-m d
- `go env` C-g e
- `go list`  C-g l
- `go version`  C-g v
- 可选：`go test -race`、覆盖率、benchmark

### 4. 调试：`delve`   （未定）
- 启动调试会话
- 断点
- 单步、继续、暂停
- 查看变量
- 查看调用栈
- 查看 goroutine
- 条件断点

### 5. 可选生态工具
- `staticcheck`
- `golangci-lint`
- `gofumpt`
- `goimports-reviser`

## 三、混合功能：编辑器 + 工具链

这些不能简单归到一边，通常是两边协作。

| 功能 | 编辑器内建负责 | 工具链集成负责 |
|---|---|---|
| 自动补全 | 触发、弹窗、选择、插入 | `gopls` 提供候选 |
| 跳转定义 | 接收跳转请求、打开文件、定位光标 | `gopls` 计算位置 |
| 查找引用 | 展示结果列表、点击跳转 | `gopls` 计算引用 |
| 重命名 | 输入新名字、预览、应用修改 | `gopls` 计算改动 |
| 实时诊断 | 画波浪线、问题面板 | `gopls` 提供错误警告 |
| 保存格式化 | 保存事件、调用命令、替换文本 | `gofmt` / `goimports` 执行 |
| 运行测试 | 按钮、快捷键、终端、输出跳转 | `go test` 执行 |
| 调试 | 断点 UI、变量面板、调用栈 | `delve` 执行 |
| 模块识别 | 识别 `go.mod`、展示项目结构 | `go list` / `go env` 解析 |
